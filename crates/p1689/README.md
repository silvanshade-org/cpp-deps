# p1689

Borrowed, `no_std`-compatible P1689 revision 5 scanner records. `DepFile::parse(JsonInput(bytes))` retains rule outputs, module identities, paths, interface status and lookup modes. Values use `Cow<[u8]>`: unescaped strings borrow input; escaped strings own unescaped bytes. Keep input alive while using parsed records. This specialized scanner parser does not validate UTF-8 or control bytes and accepts literal schema keys, not escaped keys. Structural, field, integer and escape failures return typed byte-offset diagnostics.

Field dispatch uses discriminating prefix bytes. A quote/backslash finder is initialized once per document: AVX2 or SSE2 when selected by target features, otherwise portable word scanning. Escape handling allocates lazily, reuses four-byte Unicode scratch, and uses a 256 KiB paired-hex table. Serde JSON is only a test oracle. The companion `cpp-deps` crate retains scanner buffers through graph planning and compilation; Unix paths and command arguments preserve bytes without encoding checks. Other platforms require UTF-8 at the native-string boundary.
